# Wukong Benchmark Automation

Консольный инструмент на C#, который автоматически выполняет два прохода **Black Myth: Wukong Benchmark Tool** (Steam): CPU-тест и GPU-тест. Инструмент сам применяет настройки, запускает бенчмарк, дожидается результатов, разбирает их и выводит отчёт: характеристики компьютера, результаты обоих тестов и использованные настройки.

## Запуск

1. Установите [Black Myth: Wukong Benchmark Tool](https://store.steampowered.com/app/3132990/) и **один раз запустите его вручную**: при первом запуске пользователь принимает соглашение, игра создаёт файл настроек и компилирует шейдеры.
2. Запустите Steam, закройте бенчмарк.
3. Скачайте [WukongBenchmark.exe](https://github.com/welldanov/wukong-benchmark-automation/releases/latest/download/WukongBenchmark.exe) (или со страницы [Releases](https://github.com/welldanov/wukong-benchmark-automation/releases/latest)) и запустите. Программа запросит права администратора: настройки бенчмарка лежат в `Program Files`.
4. Около 8 минут не трогайте мышь и клавиатуру: инструмент сам управляет окном игры.
5. Отчёт выводится в окне программы и сохраняется в `results/<дата_время>/report.md` рядом с exe.

Требования: Windows 10 2004+ или Windows 11, x64. .NET устанавливать не нужно, он встроен в exe. Если появится окно SmartScreen, нажмите «Подробнее» → «Выполнить в любом случае»: файл не подписан.

Параметры (необязательные): `--only cpu|gpu` — один тест, `--install-dir <папка>` — путь к бенчмарку, если он не найден в Steam автоматически, `--output <папка>` — куда сохранить отчёт.

Сборка из исходников (.NET SDK 10, терминал от администратора):

```bash
dotnet run --project src/WukongBenchmark
dotnet publish src/WukongBenchmark -c Release -o publish
```

## Выбор настроек

| Параметр | CPU-тест | GPU-тест |
|---|---|---|
| Режим экрана | оконный, 1280×720 | окно без рамок, родное разрешение монитора |
| Разрешение рендера | 640×360 (масштаб на минимуме, 25 %) | родное, масштаб 100 % |
| Пресет графики | Низкое | Реалистичное (максимальный) |
| Полная трассировка лучей | выкл. | вкл. |
| Масштабирование | TSR | TSR |
| Генерация кадров, VSync, лимит FPS | выкл. | выкл. |

**CPU-тест.** Видеокарта рендерит крошечную картинку с минимальной детализацией и готовит каждый кадр быстрее процессора. Поэтому частоту кадров ограничивает работа процессора: игровая логика, анимация, подготовка вызовов отрисовки, стриминг. Генерация кадров выключена, потому что добавляет кадры без участия процессора. VSync и лимит FPS выключены, чтобы не было искусственного потолка.

**GPU-тест.** Максимальное число пикселей без апскейла, максимальное качество всех эффектов и полная трассировка лучей. Используется монитор с наибольшим разрешением. Генерация кадров выключена, потому что маскирует реальную производительность рендера.

**TSR вместо DLSS.** TSR встроен в Unreal Engine 5 и работает на видеокартах NVIDIA, AMD и Intel, поэтому настройки одинаково применяются на любом ПК. В CPU-тесте он позволяет опустить масштаб до 25 %, а в GPU-тесте при 100 % только сглаживает и не снижает нагрузку.

Результат подтверждает выбор: по покадровым данным бенчмарка в CPU-тесте 100 % кадров ограничены процессором, в GPU-тесте 100 % — видеокартой.

## Результаты

Отчёт содержит три таблицы:

- **характеристики компьютера** — процессор (ядра/потоки, частота), видеокарта (видеопамять, драйвер), оперативная память (объём, тип, частота, модули), мониторы, накопитель, ОС, схема электропитания, версия бенчмарка;
- **результаты тестов** — значения из результата бенчмарка (средний, минимальный и максимальный FPS, 5-й перцентиль, видеопамять) и рассчитанные по его покадровым данным (1% low, среднее время кадра CPU и GPU, узкое место);
- **настройки тестов** — настройки, с которыми бенчмарк реально прошёл каждый тест. Если они отличаются от заданных инструментом, выводится предупреждение.

Пример (i5-13400F, RTX 4060, монитор 3440×1440):

| Показатель | CPU-тест | GPU-тест |
|---|---|---|
| Средний FPS | 130 | 11 |
| Минимальный / максимальный FPS | 52 / 167 | 10 / 13 |
| 5-й перцентиль / 1% low FPS | 118 / 84 | 10 / 10 |
| Видеопамять | 3.4 ГБ | 7.4 ГБ |
| Время кадра CPU / GPU | 7.7 / 4.6 мс | 11.5 / 84.3 мс |
| Кадров, ограниченных CPU | 100 % | 0 % |
| Узкое место | CPU | GPU |

Рядом с отчётом сохраняются исходные JSON-результаты бенчмарка и резервная копия его настроек.

## Как это работает

Документированного способа автоматизации у бенчмарка нет. Ниже то, что удалось установить по файлам игры и её поведению.

**Запуск.** Инструмент находит бенчмарк в библиотеках Steam (реестр → `libraryfolders.vdf` → `appmanifest_3132990.acf`) и запускает `b1_benchmark.exe`. Если запустить игру не из Steam, она перезапускается через Steam, а тот показывает окно подтверждения. Поэтому инструмент выставляет процессу те же переменные окружения, что и Steam: `SteamAppId`, `SteamGameId`, `SteamOverlayGameId`.

**Настройки.** Хранятся в `b1\Saved\Config\Windows\GameUserSettings.ini`. Значения меню лежат в строке `UISettingData`: пресет и параметры качества 1–5, `Rtx`, `InsertFrame`, метод масштабирования `SuperResolutionSampling` (2 — DLSS, 3 — TSR), `ScreenMode`, `MainDisplay`, `ImageQuality`. Рядом лежат стандартные ключи Unreal Engine: `FullscreenMode`, `ResolutionSizeX/Y`, `DesiredScreenWidth/Height`, `MainMonitorID`, `sg.*Quality`. Инструмент меняет только нужные ключи, а после тестов восстанавливает исходный файл. Важная деталь: бенчмарк показывает масштаб рендера из `ImageQuality`, но реально рендерит в разрешении `DesiredScreenWidth/Height`, поэтому инструмент задаёт оба значения.

**Запуск теста.** Тест стартует только из меню: «Нажмите любую кнопку» → «Тест быстродействия» → «Подтвердить». Клавиатура в главном меню не работает без наведения мыши. Поэтому инструмент делает снимок окна игры, распознаёт текст встроенным OCR Windows (`Windows.Media.Ocr`), определяет текущий экран и выполняет нужное действие: Enter, либо наведение курсора на найденную кнопку и Enter. После каждого действия результат проверяется следующим снимком. На незнакомом экране инструмент ничего не нажимает, а при ошибке сохраняет снимок экрана.

**Результаты.** После теста бенчмарк записывает JSON в `%TEMP%\b1\BenchMarkHistory\Tool\<unix-время>`. В нём итоговые метрики, данные о системе, применённые настройки и покадровая запись (`FrameRate`, `CPUFrameTime`, `GPUFrameTime` и др.). Появление нового файла означает конец теста. После этого бенчмарк закрывается. Новые настройки игра читает только при старте, поэтому для второго теста она запускается заново.

## Ограничения

- Только Windows. Во время прогона нельзя пользоваться мышью и клавиатурой.
- Проверено на русском интерфейсе бенчмарка версии 1.0.3.14649. Надписи английского интерфейса заданы, но не проверялись.
- Форматы файлов бенчмарка не документированы и могут измениться в будущих версиях.
